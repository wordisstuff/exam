# Question Bank Expansion Blueprint

## Goal

Build a source-checked Minnesota exam-prep bank by expanding each verified concept into multiple distinct exam-style questions rather than producing one paraphrase per source question.

The current intake contains 330 source concepts. These are topic seeds, not production questions.

## Expansion rule

For every usable concept:

1. Identify the authoritative rule, table, definition, exception, calculation, or business-law principle.
2. Build a small "rule map" of every independently testable detail.
3. Generate 2–6 genuinely different questions when the rule supports it.
4. Prefer scenario/application questions over pure recall.
5. Include realistic distractors based on nearby code numbers, exceptions, wrong thresholds, or common field mistakes.
6. Add code-book questions that require locating the correct section/table when the topic is suitable.
7. Deduplicate against the existing bank before promotion.
8. Mark production eligibility only after authoritative verification.

## Question families

A single code concept can yield several question families:

- direct minimum / maximum / required value
- exception recognition
- compliant vs noncompliant field scenario
- multi-select rule bundle
- calculation or layout
- table lookup
- sequencing / application
- "which statement is NOT permitted"
- code-navigation question
- mixed-rule scenario combining two or more requirements

Example: foundation sill anchorage can test maximum bolt spacing, minimum bolts per plate section, end placement, minimum end distance in bolt diameters, and a complete compliant layout.

## QB coverage target

Primary target: at least 1,000 strong QB questions before considering the bank mature.

Coverage should include:
- plans and specifications
- building planning and life safety
- sitework, grading and drainage
- excavation
- footings and foundations
- concrete and masonry
- carpentry, walls, floors, roofs and load paths
- roof coverings, flashing, valleys and ice barriers
- exterior finishes and water-resistive assemblies
- insulation, air sealing, vapor control and energy code
- interior finishes
- windows, doors, glazing, stairs, guards and handrails
- moisture and decay protection
- mechanical / plumbing / electrical coordination concepts within QB scope
- OSHA and job-site safety
- Minnesota contractor statutes, business, contracts, bonds, insurance, liens, payroll and licensing

## Separate exam tracks

### QB — Qualifying Builder
Active product track. Broadest residential scope and the immediate priority.

### QC — Qualifying Remodeler
Planned separate track. Reuse shared verified content where appropriate, but build remodeler-specific scenarios around existing structures, alterations, repair work and remodeling scope.

### QR — Qualifying Roofer
Planned separate track. Reuse shared safety/law questions as appropriate, but build a dedicated roofing bank around roof systems, flashing, ice barriers, ventilation, roof coverings, ladders/fall protection, contracts and Minnesota roofer-specific rules.

Do not label QC or QR content as QB merely because a topic overlaps. Questions may belong to more than one track in the future.

## Quality gate

A question is production-ready only when it has:
- original English wording
- Ukrainian translation
- 4–5 plausible answer choices
- keyed answer(s)
- concise explanation
- authoritative reference
- category/subcategory
- difficulty
- skills/tags
- no material duplication
- verified current rule
- Minnesota-specific treatment when Minnesota differs from generic model-code or federal material

## Source hierarchy

Prefer, in order:
1. Minnesota Residential Code / Minnesota Rules
2. Minnesota Statutes and DLI official manuals/guidance
3. OSHA / federal regulations where applicable
4. IRS / SSA / DOL / EPA official sources for business-law and safety topics
5. Adopted standards/manufacturer instructions when the code delegates to them

Commercial prep books are concept sources only and are never the authority for the final answer.
